# 激光 UI 原始图片

将点动等控件的 **PNG** 放在此目录（建议 48×40，带透明通道）。

推荐命名：

| 文件 | 用途 |
|------|------|
| `jog_x_plus.png` | X+ 点动 |
| `jog_x_minus.png` | X- 点动 |
| `jog_y_plus.png` | Y+ 点动 |
| `jog_y_minus.png` | Y- 点动 |
| `jog_home.png` | 回零 ◎ |

转换：运行工程根目录下 `scripts/Image_Converter/lvgl_tools_gui.py`，输出目录选 `../images/`。
