# 激光雕刻机 UI 设计系统 

> 屏幕: **480×320** 横屏 | 主区域: **276px** (除去顶栏 24px + 底栏 20px)
> 内容区: **约406×276px** (除去左侧导航浮标)
> 框架: **LVGL v8.x** (C++) | 主题: **工业 HUD 暗色**
可参考git ui_webui_v0的控件大小 


## 设计要求
1.无需照搬现有的素材，这个skills的建议只供尺寸参考。可以根据大数据的ui代码模板，重新设计样式
只要协调合理美观保留即可
2.现在切页按键（导航浮标）和点动控制盘不需要修改保持现在设计。
3.已有的各组件后端功能不变，只修改前端
4.代码自查，修复bug

## 视觉样式原则

1. **发光层次**: border(1px) → outline(2-3px) → shadow(6-14px)，由近到远三层发光
2. **按压反馈**: transform_scale 90-96%，配合 bg_color 变化
3. **圆角语言**: 卡片 6-8px，按钮 8-10px (药丸形)，圆形控件 LV_RADIUS_CIRCLE
4. **间距节奏**: 4/8/12/16px 阶梯，优先使用 8px 基准
5. **触控标准**: 最小 40px (接近 iOS 44px / Material 48px 标准)

## 布局模式

### Print 页面 — 横排操作区
```
[坐标 68] [8] [步进 68] [8] [点动面板 120×120] [8] [运控按钮 72]
                                     ↑ 垂直居中
[──────────────── 状态面板 56px ────────────────]
```

### Pick 页面 — 地图+侧栏
```
[═══ 正方形地图 ═══] [6] [坐标卡片]
[   (自适应填充)   ]     [状态文字]
[   十字光标+圆点  ]     [确定按钮]
[                  ]     [回零按钮]
```

### Settings 页面 — 纵列卡片
```
[┌─ 面板卡片 ──────────────┐]
[│ 材料设置                │]
[│ [材质下拉 ▾]           │]
[│ ─── 分割线 ───         │]
[│ 激光功率                │]
[│ [════●════] 50%        │]
[│ 运动速度                │]
[│ [══●══════] 100%       │]
[└────────────────────────┘]
[  [══════ 应用 ══════]   ]
```

## 构建说明

修改页面后需重新编译：
```bash
idf.py build
```

涉及文件：
- `pages/page_print.cc/h` — 打印/点动页面
- `pages/page_pick.cc/h` — 选取/定位页面
- `pages/page_settings.cc/h` — 设置页面
- `laser_ui_layout.h` — 全局布局常量
- `laser_ui_widgets.cc/h` — 通用控件样式
- `laser_ui_shell.cc/h` — 外壳/导航/页面切换
