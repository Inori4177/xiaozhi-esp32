## 视觉样式原则

1. **发光层次**: border(1px) → outline(2-3px) → shadow(6-14px)，由近到远三层发光
2. **按压反馈**: transform_scale 90-96%，配合 bg_color 变化
3. **圆角语言**: 卡片 6-8px，按钮 8-10px (药丸形)，圆形控件 LV_RADIUS_CIRCLE
4. **间距节奏**: 4/8/12/16px 阶梯，优先使用 8px 基准
5. **触控标准**: 最小 40px (接近 iOS 44px / Material 48px 标准)

## 构建说明

修改页面后需重新编译：
```bash
idf.py build
```

涉及文件：
- `pages/page_print.cc/h` — 打印/点动页面
- `pages/page_pick.cc/h` — 选取/定位页面
- `pages/page_settings.cc/h` — 设置页面
- `laser_ui_layout.h` — 全局布局常量
- `laser_ui_widgets.cc/h` — 通用控件样式
- `laser_ui_shell.cc/h` — 外壳/导航/页面切换
